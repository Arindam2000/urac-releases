# Install URAC

About 10 minutes. Use Wi-Fi: the first start downloads the voice models (about 300 MB).

1. On your phone, open **github.com/Arindam2000/urac-releases/releases/latest**
2. Tap the file that ends in **.apk** to download it.
3. Open the download. If Android asks, allow installs from Chrome, then tap **Install**.
4. If Play Protect warns about an unknown app, tap **More details**, then **Install anyway**.
5. Open **URAC**. Allow notifications and the microphone.
6. Wait while it downloads. The screen shows percent and time left.
7. Tap **Pair this phone** and point the camera at the code Arindam shows you.

Done when the screen says **Paired**. Hold **Talk** to send a voice message, tap **Call** to call.

New versions install themselves. On Android 11 or older, tap **Update** when it appears.
